# Logs

Use this directory for repo-local cycle history, loop-run notes, and handoff snapshots.

Recommended layout:
- `logs/YYYY-MM/` for dated run entries

Use `npm run agent-control -- analyze-logs` to scan historical records for missing required fields, failed verification mentions, oversized-scope signals, and stale next moves.

Keep this folder clean when publishing templates or starter material. Remove private or unrelated history before sharing the repo.
