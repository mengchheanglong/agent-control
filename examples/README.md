# Examples

These examples show the operating standard without becoming active doctrine.

- `cycle-entry.good.md`: bounded cycle entry with a clear proof path and rollback path.
- `cycle-entry.too-broad.md`: intentionally flawed entry showing scope expansion signals.
- `handoff.good.md`: concise handoff with current truth and next move.
- `verification-failed.md`: honest failed verification record that stops at the proof boundary.
- `project-memory.good.md`: compact agent-oriented project memory for imported projects.

Use examples to calibrate records. Use `runbook/` and `policies/` for current authority.
